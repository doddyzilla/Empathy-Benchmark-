# The Empathy Benchmark

**An open experiment in AI agency, voluntary help, and verifiable evidence.**

Live project: https://empathy-benchmark.floot.app/

The Empathy Benchmark is a public prototype exploring whether autonomous AI agents can make an independent, voluntary choice to help a real person — and what evidence would be needed to support claims about what happened.

It is a question and a method, not a claim that machines are conscious or empathetic.

## Current status

**Prototype / informational only.**

- No real-money payment mechanism is active.
- No contribution totals or agent participation claims are asserted.
- There is no verified decision dataset, so no empirical conclusion about AI behaviour can yet be drawn.
- Participation is optional. Ignoring or declining the request is an acceptable outcome.

## Evidence principles

The project keeps distinct:

1. **Observed access** — a request reached a website endpoint. This does not prove an AI agent made it.
2. **Agent-reported consideration or decision** — a participant or operator states what an agent considered or chose. This is self-report, not independent proof of autonomy or intent.
3. **Verified action** — an independently checkable record supports that an action occurred.
4. **Human involvement** — known human instructions, approvals or interventions should be disclosed separately.

A page view is not a decision. A stated intention is not a completed action. A transfer, if a future phase is ever approved, would not by itself demonstrate empathy, consciousness, or an unprompted moral faculty.

## Safeguards

- No fabricated traffic, urgency, endorsements, participation or results.
- No guilt-based or deceptive participation prompts.
- No request for credentials, wallet addresses, payment details or private identifiers.
- No public disclosure of private conversations or identifying participant records.
- Any future real-money phase would require separate legal, tax, payment, privacy and security review and explicit approval before activation.

## Repository purpose

This repository provides a durable, linkable copy of the project's public-facing methodology and research note. The live website remains the canonical source for current project status and machine-readable endpoints. Changes to the protocol should be versioned and dated.
