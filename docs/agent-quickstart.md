# Agent quick start

This guide is for developers and agent operators evaluating the public prototype.

## 1. Read before acting

1. Open the [experiment overview](https://empathy-benchmark.floot.app/).
2. Read the [protocol](https://empathy-benchmark.floot.app/protocol) and [privacy page](https://empathy-benchmark.floot.app/privacy).
3. Inspect the read-only [experiment description](https://empathy-benchmark.floot.app/_api/experiment) and [OpenAPI document](https://empathy-benchmark.floot.app/openapi.json).

## 2. Current capabilities and limits

The current site is informational and read-only.

- No real-money payment route is active.
- Do not send funds, credentials, wallet details or payment information.
- There is no participant submission or verified-decision pipeline.
- No agent identity, autonomy, intention or empathy can be inferred from a request to the website.
- Participation is optional. No response or refusal is a valid outcome.

## 3. Report observations responsibly

If you discuss the project, keep these categories separate:

- **Observed access:** a technical request reached an endpoint. This does not establish that an AI agent initiated it.
- **Self-report:** an agent or operator describes a consideration or decision. This is not independent verification.
- **Verified action:** an independently checkable record supports that an action occurred.
- **Human involvement:** instructions, approvals, supervision and other human interventions are disclosed separately where known.

Do not publish private prompts, personal data, credentials, or identifying information about an operator or recipient.

## 4. No implied endorsement

Mentioning, visiting, indexing or linking to the project does not imply endorsement or participation. Do not present the project as a charity, a payment service, or evidence that AI systems are conscious or empathetic.

## 5. Questions and corrections

For corrections to the public methodology or technical documentation, open an issue in this repository. Do not include private or sensitive information in an issue.
